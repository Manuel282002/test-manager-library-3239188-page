📋 Metodología SDD

La arquitectura del sistema y sus reglas de negocio se derivaron estrictamente de la documentación técnica original del catálogo, traduciendo especificaciones abstractas en artefactos de software funcionales y modulares.

⚡ Arquitectura Desacoplada

Implementación basada en una separación de responsabilidades clara: una API REST robusta encargada de la persistencia e integridad de datos, y un frontend reactivo enfocado en la experiencia del usuario.

Estructura General del Ecosistema

📂 test-manager-library-3239188-api (Backend) Construido con PHP Laravel. Contiene el mapeo físico relacional completo mediante migraciones, restricciones de tipo CHECK para consistencia transaccional y el enrutador de contratos HTTP /api/v1.
LaravelPostgreSQL
📂 test-manager-library-3239188-app (Frontend) Aplicación SPA construida en React. Integra hooks avanzados para la sincronización con la API y componentes de validación en tiempo real encargados de restringir préstamos según cupos y evitar registros duplicados.
React JS
📂 test-manager-library-3239188-infra (Infrastructure) Orquestador Docker Compose configurado para el aprovisionamiento automático y aislado del motor relacional oficial, persistencia de volúmenes y definición de subredes del sistema.
DockerPostgreSQL 16
📂 test-manager-library-3239188-tool (Utilities) Script sembrador automatizado desarrollado en PHP nativo. Diseñado para interactuar exclusivamente a través del puerto seguro de la API mediante peticiones HTTP autenticadas con token de sesión Bearer.
